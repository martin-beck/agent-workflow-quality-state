## Objective

Ignored Python bytecode cache artifacts must not cause privacy validation failures. Non-ignored
files must retain bounded size checking and privacy scanning.

## Acceptance evidence

- Ignored `__pycache__` artifacts are omitted from privacy findings, including size findings.
- Oversized ordinary files still fail with the existing bounded-size finding.
- Ordinary privacy-bearing files still fail with the existing privacy finding.
- Focused tests and applicable state quality checks pass.
