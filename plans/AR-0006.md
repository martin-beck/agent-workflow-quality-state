# AR-0006: Formal evidence and refactoring assurance

## Outcome

Give agents truthful, machine-readable evidence about bounded policy safety and behavior-preserving refactors.

## Scope and decomposition

- Model policy updates, exceptions, tier promotion, evidence freshness and concurrent review transitions.
- Require executable model commands, bounds, assumptions, counterexamples and implementation refinement links.
- Define refactoring contracts using characterization, differential, property and mutation tests.
- Create child ARs per model and language-specific refactoring adapter.

## Acceptance

- Known-bad model mutations produce expected counterexamples.
- Documentation states exactly what bounded models do and do not prove.
- Refactoring claims require before/after evidence and cannot be inferred from formatting alone.
