# AR-0004: Python shell documentation and schema adapters

## Outcome

Provide opt-in pinned adapters for formatting, lint, typing, tests, coverage, ShellCheck/shfmt/Bats, Markdown/link/prose checks and JSON/YAML/schema validation.

## Scope and decomposition

- Define tool discovery, version pin, argv, timeout and normalized finding contracts.
- Keep project-owned configuration authoritative and classify unavailable tools clearly.
- Add positive, negative and version-skew fixtures for each family.
- Create child ARs for Python, shell, documentation and schema implementations.

## Acceptance

- No adapter uses a shell or downloads tools during an offline check.
- Results are deterministic and redact source content by default.
- Native project commands and AWQ adapter evidence agree on controlled fixtures.

## Child ARs

- AR-0012: Python formatting, lint, typing, tests and coverage.
- AR-0013: ShellCheck, shfmt and Bats.
- AR-0014: Markdown, links and prose.
- AR-0015: JSON, YAML and JSON Schema.

The umbrella freezes the shared discovery, version, execution and result contracts. Each child
adds reviewed family contracts plus positive, negative, version-skew and native-equivalence
fixtures after the umbrella release.
