# AR-0052: Bounded TLA+ execution and admission safety

Bound every Agent Workflow Quality state-repository TLC invocation and connect it to the shared host
TLA admission boundary.

Acceptance criteria:

- every TLC invocation has explicit worker and JVM heap bounds;
- the shared admission boundary is mandatory and cannot be bypassed accidentally;
- queueing, cancellation and restart behavior are bounded and durable;
- per-job cgroup memory and swap limits contain formal-job failures;
- focused positive, queueing, cancellation and memory-limit tests pass;
- exact-head review, signed DCO commit, CI and post-merge verification are complete.
