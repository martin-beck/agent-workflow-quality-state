# AR-0015: Pinned schema quality adapters

## Outcome

Provide opt-in JSON, YAML and JSON Schema validation adapters with explicit dialect and parser
contracts.

## Scope

- Select exact reviewed parser and validator versions with offline execution.
- Reject duplicate keys, unsafe YAML constructs and unsupported schema drafts or formats.
- Resolve repository-local schema references within confined paths and bounded document sizes.
- Normalize findings without source excerpts and preserve project-owned schema/config mappings.
- Add conforming, failing, unavailable and version-skew fixtures.

## Acceptance

- JSON, YAML and JSON Schema adapters have executable positive and negative contract tests.
- Adapter and native command outcomes agree on controlled fixtures.
- Draft, format-checker and reference-resolution limitations are explicit.
- Offline execution never installs, downloads or resolves remote references.
