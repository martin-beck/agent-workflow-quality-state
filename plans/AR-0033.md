# AR-0033: Agent-ready quality integration workflow

## Outcome

AWQ provides an agent-readable integration recipe covering profile initialization, terminology adoption, native-gate mapping, CI ordering, review, release, and fresh-clone checks.

## Acceptance

- The recipe is generated from current schemas and release metadata.
- It distinguishes diagnostics, explicit mutations, native gates, and authenticated release operations.
- It has portable CI and offline source/wheel paths.
- Consumer integration remains project-owned and does not add coordinator behavior to AWQ runtime code.
