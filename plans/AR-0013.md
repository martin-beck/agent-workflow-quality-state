# AR-0013: Pinned shell quality adapters

## Outcome

Provide opt-in ShellCheck, shfmt and Bats adapters with portable, deterministic evidence.

## Scope

- Pin reviewed ShellCheck, shfmt and Bats versions and exact version probes.
- Preserve repository configuration and explicit project test argv.
- Use argument arrays without a shell, bounded deadlines and content-minimized findings.
- Cover executable and non-executable shell files without treating fixtures as first-party source.
- Add conforming, failing, unavailable and version-skew fixtures.

## Acceptance

- Static analysis, format and test adapters have executable positive and negative contract tests.
- Adapter and native command outcomes agree on controlled fixtures.
- Shell dialect and platform limitations are explicit.
- Offline execution never installs or downloads a tool.
