# AR-0028: Language-specific refactoring evidence adapters

## Outcome

Consumers can collect the four AR-0006 evidence methods for a reviewed language without weakening privacy, determinism, bounds or native gates.

## Acceptance

- First language adapter has versioned contract, exact argv/tool pins, bounded resources and offline installation with no runtime dependency.
- Characterization, differential, property and mutation evidence has independent native fixtures, mismatch/survivor/error tests and normalized privacy-safe output.
- Unsupported language/tool/platform combinations fail closed and remain documented.
