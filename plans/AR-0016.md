# AR-0016: Huawei and MIT source-header compliance

## Outcome

Require the exact Huawei Technologies 2026 copyright immediately before the SPDX MIT identifier
in every reviewed first-party AWQ source file.

## Scope

- Inventory tracked executable and test sources using Git's NUL-delimited file list.
- Add canonical headers without moving interpreter shebangs.
- Add a deterministic non-mutating checker with positive and hostile-path tests.
- Add a dedicated pull-request CI step and document the reviewed source-format boundary.
- Exclude generated fixtures and vendored source explicitly rather than rewriting external content.
- Keep the state-vendored coordinator unchanged until an upstream release can be verified and synced.

## Acceptance

- Every selected first-party source has one exact adjacent Huawei 2026 and SPDX MIT header.
- Wrong text, order, placement, duplicates, encoding and path edge cases fail deterministically.
- Formatting, lint, strict typing, branch coverage, catalogue generation, doctor and PR-tier AWQ
  checks pass on the exact candidate.
- The staged diff contains no generated drift, vendored changes, private evidence or unrelated work.
