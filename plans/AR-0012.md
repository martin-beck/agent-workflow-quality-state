# AR-0012: Pinned Python quality adapters

## Outcome

Provide opt-in Python adapters for formatting, linting, strict typing, tests and branch-aware
coverage without replacing project-owned configuration.

## Scope

- Add reviewed exact-version contracts for Ruff and mypy plus explicit project test and coverage
  argv.
- Discover tools without installation, invoke argument arrays without a shell and enforce deadlines.
- Normalize status, tool/version identity and content-minimized findings without source excerpts.
- Exercise pyproject-owned settings and supported Python versions.
- Add conforming, failing, missing-tool and version-skew fixtures.

## Acceptance

- Ruff format/check, mypy, unittest or pytest, and coverage adapters have executable contract tests.
- Adapter and native command results agree on controlled positive and negative fixtures.
- Missing or mismatched tools fail with stable classifications and remediation.
- Offline execution performs no package resolution or download.
