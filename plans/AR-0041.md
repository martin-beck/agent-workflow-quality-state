# AR-0041: Execution budgets and process-boundary receipts

## Outcome

AWQ can represent multidimensional execution budgets, uncertainty and process cleanup without overstating observation as enforced isolation.

## Scope

- Define bounded dimensions for wall time, actions, tokens, cost, CPU, memory, PIDs, disk and output.
- Classify every dimension as `enforced`, `observed`, `estimated` or `unavailable`, with tool and measurement provenance.
- Model reserve-before-effect, settlement, refund, stale reservation and over-settlement behavior for actions that can create external effects.
- Extend process receipts with argv digest, minimal environment classification, process-group/session policy, deadline, TERM/KILL escalation, descendants and orphan outcome.
- Add optional sandbox observations for network, filesystem and capability boundaries while retaining the documented trusted-executable limitation.

## Acceptance

- Property and bounded-model fixtures establish conservation, non-negative balances, single settlement and bounded termination invariants.
- Negative fixtures cover incomplete budgets, stale reservations, over-settlement, unknown units, missing cleanup, surviving descendants and unsupported isolation claims.
- Evidence excludes argv contents, environment values, output and machine-specific paths.
- Current AWQ adapter lifecycle tests map cleanly into the new receipt.
- No core profile begins requiring a platform-specific sandbox.

## Non-goals

AWQ does not provide portable containment, billing reconciliation, benchmark scheduling or resource enforcement where the host cannot prove it.
