# AR-0021: Pinned Rust supply and API compatibility gates

## Outcome

Provide opt-in, exact-version Rust dependency-policy, advisory and public API compatibility
contracts whose databases, baselines and offline limitations are review-visible.

## Scope

- Pin cargo-deny, cargo-audit and cargo-semver-checks releases with checksum-verified bounded atomic
  Linux x86-64 acquisition.
- Keep license/source/duplicate/yank policy, advisory database snapshot and semver baseline
  repository-owned or immutable-digest identified.
- Add locked/offline commands that never fetch indexes, advisories, crates or baselines at runtime.
- Distinguish policy violations, known-advisory observations and API compatibility from correctness,
  provenance, exploitability and actual downstream impact.
- Add controlled crates for disallowed license/source policy, lock drift, known advisory fixtures and
  public API breakage, with native-command equivalence and stale/missing database behavior.

## Acceptance

- Exact tool probes and positive/independent negative fixtures pass on Linux x86-64.
- Network-disabled runtime is proven; absent/stale snapshots and baselines fail closed with explicit
  remediation rather than silently fetching.
- Findings omit upstream diagnostic text and private crate/source paths.
- Semver evidence names the compared baseline and cannot be interpreted as full behavioral
  compatibility.
- Full AWQ gates, hosted exact-head/main CI, signed/DCO publication, a public release and
  credential-free tagged installer/wheel/native-contract smoke pass.
