# AR-0014: Pinned documentation quality adapters

## Outcome

Provide opt-in Markdown structure/style, internal link and prose adapters while preserving truthful
offline evidence boundaries.

## Scope

- Select exact reviewed tool versions whose relevant checks can run without network access.
- Keep repository dictionaries, ignore rules and tool configuration authoritative.
- Separate deterministic local-link checks from any explicitly scheduled external-link observation.
- Normalize findings without retaining prose excerpts or private paths.
- Add conforming, failing, unavailable and version-skew fixtures.

## Acceptance

- Markdown, local-link and prose adapters have executable positive and negative contract tests.
- Adapter and native command outcomes agree on controlled fixtures.
- External availability is never claimed by an offline result.
- Offline execution never installs, downloads or contacts a service.
