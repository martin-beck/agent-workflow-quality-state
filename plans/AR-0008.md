# AR-0008: Consumer equivalence and enforcement promotion

## Outcome

Promote only shared gates proven equivalent or stronger than project-native gates, with independent decisions for each consumer.

## Scope and decomposition

- Capture content-minimized shadow outcomes, runtime, flake and mismatch categories.
- Build controlled positive and negative corpora from each consumer's existing gates.
- Define minimum observation windows and rollback criteria.
- Decompose promotion into one child AR per repository; never remove coordination tooling.

## Acceptance

- No native gate is removed without reviewed equivalence evidence.
- False negatives block promotion; false positives have owned remediation.
- Enforcement and rollback changes use each consumer's coordinator and PR process.
