# AR-0031: Formal-model adapter profile

## Outcome

AWQ offers a reviewed bounded formal-model adapter for TLA+/TLC-style tools with exact pins, model/config inputs, timeout, evidence class, and honest limitations.

## Acceptance

- Schema-validated contracts reject unbounded or dynamically constructed commands.
- Output is bounded, privacy-safe, normalized, and never claims implementation proof.
- Missing tools, unsupported models, timeout, malformed output, and model failure have distinct fixtures.
- Independent native-equivalence and full AWQ gates pass.
