# AR-0042: Agent runtime replay and execution provenance

## Outcome

AWQ defines deterministic offline replay and secret-free agent launch evidence while keeping synthetic fixtures, live compatibility and uncertain effects distinct.

## Scope

- Define canonical versioned cassettes with hard bounds for bytes, interactions, events, frames, headers, retries and virtual time.
- Require explicit request matching and normalization, ordered correlation, complete consumption and versioned pre-serialization redaction.
- Represent seeded delay, reset, truncation, cancellation and uncertain-delivery faults; uncertain delivery prohibits automatic retry unless a consumer supplies an idempotency proof.
- Define launch provenance for adapter, provider, model, settings, runtime/executable, workload, source, run/attempt, argv/environment bounds, prompt transport, network and telemetry declarations.
- Store credential resolver identity only, never values, prompts, transcripts or provider responses.

## Acceptance

- Fixtures prove deterministic replay, canonical digests and redaction before serialization.
- Hostile cases cover unconsumed frames, ambiguous matches, reordered events, limit breaches, unknown redaction versions, retry after uncertainty and synthetic evidence promoted to live.
- Multi-adapter parity is atomic: unsupported preservation fails the declared set rather than silently dropping settings.
- Runtime execution remains opt-in, pinned and offline; live observations use a separate environmental evidence class.
- Generated documentation states explicit verified behaviors and non-claims.

## Non-goals

AWQ does not implement provider dialects, store conversations, contact services or claim model quality.
