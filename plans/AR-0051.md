# AR-0051: Version-coupled release preparation for v0.33.0

## Outcome

Prepare the merged evidence-lineage contract for a truthful v0.33.0 release by
making the version, generated fixtures, catalog, provenance, SBOM, manifest,
tag, and public artifacts agree on one immutable source identity.

## Scope

- Start only from the exact AR-0043 merge commit `7debe212ffe94f40e23d57486f211037407e05b3`.
- Update the package version and every version-coupled generated/public fixture through the reviewed evolution path.
- Preserve all AR-0040/AR-0041/AR-0043 contracts, native coordinator gates, and offline-after-install boundaries.
- Re-run focused, full, generated, schema, model, privacy, deterministic-build, and release gates.
- Publish only a clean signed DCO PR, await exact-head CI and independent review, then create the signed v0.33.0 tag and six verified assets.

## Acceptance

- No source, catalog, SBOM, provenance, manifest, archive, or release asset claims `0.33.0` unless it is derived from the exact reviewed merge lineage.
- Version bump is covered by positive and negative tests, including rejection of mixed-version artifacts and stale source digests.
- Commit and annotated tag are SSH-signed with matching DCO; exact-head CI, attestation, asset hashes, and fresh public clone/download/offline install all pass.
- Public evidence contains no private paths, host data, credentials, prompts, or unbounded logs.
- The immutable v0.32.0 release is never overwritten or retagged.

## Non-goals

Do not weaken release gates, mutate the existing v0.32.0 release, or treat a
successful build with the old version as evidence for v0.33.0.
