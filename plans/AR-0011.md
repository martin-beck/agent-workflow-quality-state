# AR-0011: Agent onboarding, distribution and compatibility

## Outcome

Let a new coding agent inspect, adopt, explain, update and troubleshoot AWQ predictably without hidden host assumptions.

## Scope and decomposition

- Add machine-readable compatibility and migration metadata for AWQ, Python and platforms.
- Publish minimal pinned GitHub workflow, local wrapper and agent-instruction recipes.
- Add update previews, remediation links and stable exit-code documentation.
- Evaluate package-index and source-pin distribution without adding runtime network dependence.

## Acceptance

- Fresh Linux, macOS and Windows checkouts follow tested documented paths.
- Upgrade and downgrade fixtures preserve explicit policy review.
- Agent output is bounded, actionable and never claims unavailable capabilities.
