# AR-0005: Rust and Android JVM assurance profiles

## Outcome

Cover Rust and Android/JVM formatting, static analysis, dependency integrity, API compatibility and test evidence without pretending one tool proves runtime behavior.

## Scope and decomposition

- Rust: fmt, clippy, deny/audit, semver, coverage, fuzz and mutation evidence.
- Android/JVM: Gradle verification, wrapper integrity, Spotless, detekt/lint, ABI and UI-boundary tests.
- Pin supported toolchains and make platform or hardware constraints explicit.
- Split Rust and Android/JVM into child ARs before implementation.

## Acceptance

- Broken dependency, ABI, lint and test fixtures fail in their owning profile.
- Network, emulator and trusted-host needs are separate tiers.
- Consumer-native gates remain available for equivalence comparison.
